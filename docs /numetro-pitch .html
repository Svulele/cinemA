Website redesign — concept pitch

A cinema site that leads with what's showing tonight

A rounded, glass-and-classic visual direction built around one goal: get someone from landing on the homepage to a booked seat in three taps. This document summarises the design direction and the technology recommended to build it for production.

Design direction

Liquid glass, rounded, classic

Frosted, layered glass panels with soft inner highlights sit over a warm gradient backdrop. Pill-shaped buttons and 24–40px corner radii replace the old site's sharp edges throughout.

Bodoni + Hanken Grotesk

A classic didone serif for film titles and headings gives it a marquee, old-cinema feel; a clean grotesque carries every button, chip and label so the UI stays crisp.

Key features in the concept

Hero carousel

Arrow- and dot-driven carousel of current films, each with its own showtimes panel — replaces the old empty hero.

Choose an experience

Standard, VIP, Xtreme, 4DX and ScreenX as a collapsible set of cards; tapping one filters the film grid instantly.

Search

Quick "find a movie" sheet that filters by title or genre as you type.

Seat booking flow

Tap a showtime → seat map → ticket-stub summary, all in one sheet, three taps deep from the homepage.

Mobile-first grid

Two films per row on phones instead of one, with theme-aware light/dark styling throughout.

Recommended build stack

This concept is a single self-contained HTML/CSS/JS file, built for fast iteration in conversation. For a production build, this is the recommended stack:

LayerChoiceWhy
FrontendNext.js (React) + TypeScriptServer-rendered pages for fast first paint on the film grid; typed code reduces bugs once real payments are involved.
StylingTailwind CSSMaps directly onto this design's existing spacing, radius and color tokens — a port, not a rewrite.
Booking & paymentsExisting Nu Metro booking API where possible; Stripe or PayFast if a new service is neededSeat inventory and payments are the highest-risk part of the system — reuse what's already trusted rather than rebuilding it.
HostingVercel or similarMatches Next.js's deployment model with minimal ops overhead.
This front end is designed to be a new skin over Nu Metro's existing ticketing and payments systems, not a replacement for them.
